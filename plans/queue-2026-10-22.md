    model's view (`operationReceiptsForModel` in `domain/capability.ts`,
    applied in `boundToolResultForModel` before the bound). A succeeded
    call's succeeded receipts leave the view as `succeededOperations: N`;

    reconciles what acted without a replay (the study's "a cell that ends
    without its result keeps full receipts"). The count stays because a
    cell that shows nothing still says its calls ran (about 6 tokens). The
    view reads only the stored part, no tool registry: the advertised tool
    set flips between cell-only and native turns, and a registry-dependent
    view would change the bytes of earlier results and miss the cache.
    Old results have the same shape, so they get the same view. A session
    resumed across the upgrade pays one cache miss on its first request.
    `totalChars` in a bounded result counts the stored text, every receipt
    included, which is what `context.read` pages. Readers of `operations`,
